A SERVER-SIDE CONNECTION

Connect your Google AI backend.

This page must be served by the included Node server. A static HTML preview cannot securely call Google on its own.

  1. Copy .env.example to .env in the downloaded website folder.
  2. Put your Google API key only in GOOGLE_API_KEY on that server. Check billing, model access, and provider spending controls.
  3. Run npm start with Node.js 20 or later. Open the printed local address.
  4. Copy the APP ACCESS TOKEN printed in that server's terminal and enter it below.

The app token stays in memory for this page session. Your Google key stays on the server. Disconnecting does not cancel requests already submitted to Google. Use this shared-token server only as a single-owner workspace.
