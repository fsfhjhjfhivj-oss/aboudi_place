Milaf Studio is an independent prompt library and creative planning workspace. It is not affiliated with Higgsfield. There is no connected image or video model, cloud account, payment service, or automatic AI enhancement.

Reference files are resized locally before saving. Favorites, imported prompts, and projects use this browser's storage. Clearing that storage can remove them. Export backups. Do not import files you do not trust or include sensitive images without permission.

The included editorial artwork is AI-created inspiration. It is not a preview of what an individual prompt will produce. Brief-completeness indicators count supplied inputs; they do not predict model quality.

To add real generation, use a secure backend and an authorized provider integration. Never put secret API keys in this static website.
