# Client production brief — fill in before sharing

**Instructions for the receiving agent:** Read this as the client's production brief. Ask for a missing subject or required reference before rendering. Use an available, authorized generator that supports the selected medium. Confirm aspect ratio, video duration, and reference support; ask before material substitutions or paid generation if permission is unclear. If you cannot render, return the final prompt and settings instead. Never claim to have generated media you cannot return.

## Output and review
For a photo, make one coherent frame. For video, make one continuous shot unless the brief calls for a sequence. Check identity, geometry, light direction, and unwanted text. For video, check the opening, middle, and final frames for unintended cuts or drift. Provide the actual media if rendered. State any deviations and propose one useful revision.
